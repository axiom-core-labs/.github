# .github

Org-wide default community health files for [axiom-core-labs](https://github.com/axiom-core-labs).
Files here apply to any org repo that doesn't provide its own — see GitHub's docs on
[creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization).
