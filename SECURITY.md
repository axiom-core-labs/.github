# Security Policy

## Scope

Covers sites and services Axiom Core Labs builds and hosts for clients (Astro sites, webapps,
webstores, agent/automation services on Cloudflare Pages and related infra). Client-owned
infrastructure outside our deployment is out of scope — report those directly to the client.

## Reporting a vulnerability

Report privately via [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
on the affected repo, or email `TODO: security@axiomcorelabs.example` if you can't use GitHub.

**Do not open a public issue for a vulnerability.** Never post client data, credentials, API
keys, or patient-related information in an issue, PR, or advisory comment — redact before
reporting.
